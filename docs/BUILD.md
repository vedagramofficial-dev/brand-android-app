# VEDA IPTV — сборка и проверка

## Что уже сделано
- Ветка feature/veda-iptv-scale.
- Room-модель плейлистов, каналов, избранного и недавних каналов.
- Загрузка и разбор M3U/M3U8.
- Экран плейлистов, каналов и полноэкранный плеер.
- Категории из group-title / EXTGRP.
- Поиск, избранное и недавние каналы.
- Русский интерфейс.

## Что нужно сделать перед merge в main
1. Запустить Gradle build.
2. Исправить ошибки компиляции, если они появятся.
3. Установить APK на Android.
4. Добавить рабочий M3U/M3U8 плейлист.
5. Проверить категории, поиск, избранное, недавние и воспроизведение.
6. После успешной проверки объединить ветку с main.

## Важно
- Не объединять ветку с main до успешной сборки и ручной проверки.
- Не добавлять EPG, Chromecast, Xtream Codes и DRM в этот этап.
- Использовать только собственные или разрешённые плейлисты.
